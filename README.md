# Askewsoft.com

This is an Astro based content site to highlight a portfolio of software projects.

## 🧞 Commands

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |

## 🚀 Deploy
1. `npm run build`
1. `npm run preview`
1. Manually copy the `dist` folder content to S3
1. Confirm deployment at https://askewsoft.com where it is served via CloudFront & Route 53
